# REQ-005 数据权限与系统字段优化

## 需求概述
1. 修复系统字段不可见问题
2. 实现灵活的客户数据权限控制
3. 支持修改客户跟进人

## 问题分析

### 问题 A：系统字段不可见
**原因**：之前为实现租户隔离，字段查询只返回 `tenant_id == 当前租户` 的字段，但系统字段的 `tenant_id = NULL`，导致租户看不到。

**正确逻辑**：租户可见字段 = 系统字段(tenant_id=NULL) + 自定义字段(tenant_id=租户ID)

### 问题 B：数据权限不够灵活
**当前状态**：权限硬编码为 role 判断，只有 user 角色会过滤 managed_by

**期望**：
- self: 仅看自己跟进的客户
- team: 看自己 + 直属下属跟进的客户
- all: 看租户内所有客户

## 技术方案

### 1. 修复系统字段查询

```python
# field_definitions.py
def get_field_query(db, current_user, tenant_id):
    query = db.query(FieldDefinition)

    if effective_tenant_id:
        # 系统字段 + 租户自定义字段
        query = query.filter(
            (FieldDefinition.tenant_id == None) |
            (FieldDefinition.tenant_id == effective_tenant_id)
        )
    return query
```

### 2. 数据库变更

```sql
-- 用户表增加字段
ALTER TABLE tn_users ADD COLUMN manager_id INT COMMENT '直属上级ID';
ALTER TABLE tn_users ADD COLUMN data_scope ENUM('self', 'team', 'all') DEFAULT 'self' COMMENT '数据权限范围';

-- 添加外键（可选）
ALTER TABLE tn_users ADD CONSTRAINT fk_user_manager
    FOREIGN KEY (manager_id) REFERENCES tn_users(id) ON DELETE SET NULL;
```

### 3. 客户查询权限逻辑

```python
def get_customer_query(db, current_user, tenant_id):
    query = db.query(Customer)

    # 租户隔离
    query = query.filter(Customer.tenant_id == effective_tenant_id)

    # 数据权限
    if current_user.is_super_admin or current_user.role == 'tenant_admin':
        return query  # 管理员看全部

    if current_user.data_scope == 'all':
        return query
    elif current_user.data_scope == 'team':
        # 获取直属下属ID列表
        subordinate_ids = get_subordinate_ids(db, current_user.id)
        user_ids = [current_user.id] + subordinate_ids
        query = query.filter(Customer.managed_by.in_(user_ids))
    else:  # self
        query = query.filter(Customer.managed_by == current_user.id)

    return query
```
