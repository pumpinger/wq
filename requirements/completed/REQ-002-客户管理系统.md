# REQ-002 客户管理系统

## 需求概述
外勤管理软件的客户管理模块，支持多模板、多字段的客户信息录入。

## 功能需求

### 1. 客户模板管理
- 创建/编辑/删除客户模板
- 每个模板可配置不同的字段集合
- 模板名称、描述

### 2. 字段定义管理
- 支持的字段类型：
  - 单选（radio/select）
  - 多选（checkbox/multi-select）
  - 文本（text）
  - 数字（number）
  - 日期（date）
- 预设字段：行业、等级、区域等
- 字段属性：名称、类型、选项值、是否必填

### 3. 客户管理
- 添加客户时选择模板
- 根据模板动态渲染表单
- 客户列表展示
- 客户详情查看/编辑
- 客户删除

## 技术方案

### 后端
- **框架**: Python FastAPI
- **数据库**: MySQL 8.0
- **ORM**: SQLAlchemy

### 前端
- **框架**: React 18
- **UI库**: Ant Design
- **状态管理**: React Query

### 数据库设计

```sql
-- 字段定义表
CREATE TABLE field_definitions (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL COMMENT '字段名称',
    field_key VARCHAR(50) NOT NULL UNIQUE COMMENT '字段键名',
    field_type ENUM('text', 'number', 'date', 'select', 'multi_select') NOT NULL,
    options JSON COMMENT '选项值（用于select/multi_select）',
    is_system BOOLEAN DEFAULT FALSE COMMENT '是否系统预设字段',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 客户模板表
CREATE TABLE customer_templates (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL COMMENT '模板名称',
    description TEXT COMMENT '模板描述',
    is_default BOOLEAN DEFAULT FALSE COMMENT '是否默认模板',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 模板-字段关联表
CREATE TABLE template_fields (
    id INT PRIMARY KEY AUTO_INCREMENT,
    template_id INT NOT NULL,
    field_id INT NOT NULL,
    is_required BOOLEAN DEFAULT FALSE COMMENT '是否必填',
    sort_order INT DEFAULT 0 COMMENT '排序',
    FOREIGN KEY (template_id) REFERENCES customer_templates(id) ON DELETE CASCADE,
    FOREIGN KEY (field_id) REFERENCES field_definitions(id) ON DELETE CASCADE,
    UNIQUE KEY uk_template_field (template_id, field_id)
);

-- 客户表
CREATE TABLE customers (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(200) NOT NULL COMMENT '客户名称',
    template_id INT NOT NULL COMMENT '使用的模板',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (template_id) REFERENCES customer_templates(id)
);

-- 客户字段值表
CREATE TABLE customer_field_values (
    id INT PRIMARY KEY AUTO_INCREMENT,
    customer_id INT NOT NULL,
    field_id INT NOT NULL,
    value JSON COMMENT '字段值',
    FOREIGN KEY (customer_id) REFERENCES customers(id) ON DELETE CASCADE,
    FOREIGN KEY (field_id) REFERENCES field_definitions(id),
    UNIQUE KEY uk_customer_field (customer_id, field_id)
);
```
