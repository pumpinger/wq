# REQ-008 客户公海

## 需求概述
实现客户公海功能，支持未分配客户的集中管理、员工认领、客户释放和自动回收。

## 功能需求

### 1. 公海池列表
- 展示所有 `managed_by = NULL` 的客户
- 本租户所有员工可查看公海客户
- 支持按模板、字段值筛选
- 显示客户进入公海的时间和原因

### 2. 客户认领
- 员工可从公海认领客户
- 认领后 `managed_by` 设为当前用户
- 可设置认领上限（可选，后续实现）

### 3. 客户释放
- 员工可主动将客户释放到公海
- 管理员可将任意客户释放到公海
- 释放时记录原因

### 4. 自动回收规则
- 超过 N 天未跟进自动回收到公海
- 需要跟进记录表支持
- 可配置回收天数（租户级别）

## 技术方案

### 数据模型变更

1. 客户表已有 `managed_by` 字段，`NULL` 表示公海客户

2. 新增公海记录表 `tn_customer_pool_records`：
   - id, customer_id, tenant_id
   - action: 'release' | 'claim' | 'auto_reclaim'
   - from_user_id, to_user_id
   - reason, created_at

3. 新增租户配置（后续实现）：
   - auto_reclaim_days: 自动回收天数

### 后端接口

```
GET  /customers/pool          # 公海列表
POST /customers/{id}/claim    # 认领客户
POST /customers/{id}/release  # 释放客户
GET  /customers/{id}/pool-history  # 公海历史
```

### 前端页面

- 新建 `CustomerPool.tsx` 公海列表页面
- 在客户详情中添加释放按钮
