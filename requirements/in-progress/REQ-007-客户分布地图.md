# REQ-007 客户分布地图

## 需求概述
实现客户分布地图功能，可视化展示客户地理位置分布，支持按属性筛选。

## 功能需求

### 1. 地图展示
- 在高德地图上显示所有有坐标的客户
- 每个客户用点标记(Marker)显示
- 点击标记显示客户基本信息（名称、地址、模板等）

### 2. 筛选功能
- 按模板筛选
- 按客户字段值筛选（如：行业、规模等）
- 实时更新地图显示

### 3. 交互功能
- 点击标记弹出信息窗口
- 支持缩放和拖动
- 聚合显示（大量点位时）

## 技术方案

### 地图服务
- 使用 OpenStreetMap + Leaflet（开源免费，无需 API Key）
- react-leaflet 封装

### 前端实现
- 新建 `CustomerMap.tsx` 页面
- 使用 `react-leaflet` 组件库
- 筛选面板使用 Ant Design 组件

### 后端接口
- 复用现有 `/customers/` 接口
- 可选：添加专门的地图查询接口（返回精简数据）

## 数据依赖
- 客户表已有 `latitude` 和 `longitude` 字段
- 需要客户录入时填写坐标（可后续添加地址解析）
