# 客户管理 - 多模板动态表单设计

## 问题描述
需要实现支持多模板、多字段类型的客户管理系统，不同模板有不同的录入字段。

## 触发条件
- 客户属性需要灵活配置
- 不同业务场景需要不同的录入模板
- 字段类型包含单选、多选、文本、数字、日期等

## 解决方案

### 数据库设计（关键表）
1. **tn_field_definitions** - 字段定义表
   - 存储所有可用字段的元信息
   - field_type: text/number/date/select/multi_select
   - options: JSON 存储选项值

2. **tn_customer_templates** - 模板表
   - 模板基本信息

3. **tn_template_fields** - 模板-字段关联表
   - 定义模板使用哪些字段
   - is_required: 是否必填
   - sort_order: 显示顺序

4. **tn_customer_field_values** - 客户字段值表
   - value: JSON 存储，兼容各种类型

### 后端 API 设计
- FastAPI + SQLAlchemy
- 使用 joinedload 预加载关联数据减少查询次数
- 模板更新时先删除旧关联再重建

### 前端动态表单实现
- 根据模板获取字段配置
- 使用 switch/case 根据 field_type 渲染不同组件
- Ant Design 的 Transfer 组件用于字段选择

## 校验方式
1. 后端单元测试通过 (13个测试)
2. API 端点正常响应
3. 数据库数据正确存储

## 注意事项
1. SQLAlchemy 的 create_all 不会修改已存在的表，需要手动迁移添加字段
2. MySQL MCP Server 默认只读，写操作需要 Python 脚本
3. Windows 环境下 curl 发送中文 JSON 可能有编码问题，建议用文件方式
