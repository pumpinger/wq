# 历史经验沉淀

此目录存放开发过程中积累的经验、踩坑记录、解决方案。

## 文档命名规范
- `{场景}-{问题描述}.md`
- 例如：`表单提交-文件上传超时处理.md`

## 文档模板

```markdown
# {问题标题}

## 问题描述
简述遇到的问题

## 触发条件
- 什么情况下会遇到这个问题

## 解决方案
具体的解决方法

## 校验方式
如何验证问题已解决

## 关联文档
- 相关的其他文档链接
```
