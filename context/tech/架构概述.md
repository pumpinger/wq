## 多租户架构

### 数据隔离

采用**共享数据库 + 租户 ID 隔离**模式：

```
┌─────────────────────────────────────────┐
│              共享数据库                  │
├─────────────────────────────────────────┤
│  tenants     │ 租户表                   │
│  users       │ 用户表 (tenant_id)       │
│  customers   │ 客户表 (tenant_id)       │
│  templates   │ 模板表 (tenant_id)       │
│  fields      │ 字段表 (tenant_id)       │
│  roles       │ 角色表 (tenant_id)       │
└─────────────────────────────────────────┘
```

### 隔离实现

1. **中间件层**: 从 JWT 解析租户 ID
2. **查询层**: 所有查询自动添加 `tenant_id` 过滤
3. **权限层**: 校验用户是否属于当前租户

## 权限系统 (RBAC)

### 角色层级

```
超级管理员 (is_superadmin=True)
    │
    └── 租户管理员 (is_admin=True)
            │
            └── 普通用户 (角色权限)
```

### 数据权限 (data_scope)

| 范围 | 说明 |
|------|------|
| `self` | 只能看自己的数据 |
| `team` | 能看自己和下属的数据 |
| `all` | 能看租户内所有数据 |

### 权限码

```python
permissions = [
    "customer:create",
    "customer:read",
    "customer:update",
    "customer:delete",
    "customer:export",
    "template:manage",
    "field:manage",
    "user:manage",
    "role:manage",
]
```

## 核心数据模型

### 实体关系

```
Tenant (租户)
  │
  ├── User (用户) ─── Role (角色)
  │
  ├── FieldDefinition (字段定义)
  │
  ├── CustomerTemplate (客户模板)
  │     │
  │     └── TemplateField (模板字段关联)
  │
  └── Customer (客户)
        │
        └── CustomerFieldValue (字段值)
```

### 动态表单设计

```
FieldDefinition (字段定义)
├── field_key: 字段键名
├── field_name: 显示名称
├── field_type: 类型 (text/number/select/date/...)
└── options: 选项配置 (JSON)

CustomerTemplate (客户模板)
├── template_fields: 关联的字段列表
└── 支持配置必填、排序

Customer (客户)
├── template_id: 使用的模板
└── field_values: 动态字段值 (JSON)
```

## API 设计

### RESTful 规范

```
GET    /api/customers          # 列表
POST   /api/customers          # 创建
GET    /api/customers/{id}     # 详情
PUT    /api/customers/{id}     # 更新
DELETE /api/customers/{id}     # 删除
```

### 认证流程

```
1. POST /api/auth/login → 获取 JWT Token
2. 请求头携带: Authorization: Bearer {token}
3. 服务端验证 token，解析 user_id 和 tenant_id
```

## 区域权限模块

### 数据模型
```
Region (区域)
├── id, name, code, tenant_id
├── parent_id (预留层级)
└── sort_order

UserRegion (用户-区域关联)
├── user_id → User
└── region_id → Region
```

### 权限控制流程
```
1. Tenant.enable_region_scope = True → 启用区域权限
2. 管理员为员工分配 Region (UserRegion)
3. 客户查询时:
   - get_customer_query() 检查 enable_region_scope
   - 有分配区域 → filter(Customer.region_id.in_(user_region_ids))
   - 未分配区域 → filter(Customer.region_id.is_(None))
4. 超管和租户管理员不受区域限制
```

## 客户公海模块

### 设计
```
客户状态由 managed_by 字段决定:
├── managed_by = 用户ID → 私有客户（有负责人）
└── managed_by = NULL   → 公海客户（无负责人）

操作:
├── 释放(release): managed_by = NULL, 记录 reason
├── 认领(claim): managed_by = 当前用户
└── 自动回收(auto_reclaim): 系统定时任务（预留）
```

### 数据模型
```
CustomerPoolRecord (公海操作记录)
├── customer_id → Customer
├── action: release|claim|auto_reclaim
├── from_user_id, to_user_id
├── reason
└── created_at
```

### API
```
GET    /api/customers/pool/              # 公海客户列表
POST   /api/customers/pool/{id}/claim    # 认领
POST   /api/customers/pool/{id}/release  # 释放
GET    /api/customers/pool/{id}/history  # 操作历史
```
